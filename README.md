#  Smart Energy Management System (SEMS)

##  Overview

A web-based dashboard to monitor and manage energy consumption in a smart environment. The system provides real-time insights through interactive charts and device control simulation.

##  Features

*  Interactive energy usage charts
*  Dark mode toggle
*  Responsive design
*  Device control simulation
*  KPI cards for energy metrics

##  Tech Stack
